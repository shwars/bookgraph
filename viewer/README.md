# Атлас «Бесприданницы»

Откройте `index.html` двойным кликом в современном Chrome, Edge или другом браузере с поддержкой SVG и JavaScript. Сервер, интернет и Node.js для просмотра не нужны. Каталог `viewer` должен находиться рядом с `wiki` и `source`: существующие изображения используются по относительным путям.

## Просмотр

- **Персонажи**: портреты, пол, три размера по редакторской оценке роли и подписанные направленные отношения. Размер не зависит от числа фактов или рёбер.
- **События: хронология**: один узел на событие, примерный порядок по тексту пьесы (первое упоминание), дорожки по местам. Повторные появления доступны в карточке. Это порядок изложения, а не точный календарь; расстояние не означает длительность.
- **События: зависимости**: причины, условия и препятствия; отдельный переключатель «раньше». События без установленных зависимостей сохраняются.

Наведение мыши показывает заметку справа, клик закрепляет её. Клик по ребру открывает объяснение, статусы и все исходные факты. Кнопка «Закреплено · снять» возвращает просмотр при наведении. Цвет пола дублируется легендой; неизвестный пол отображается нейтрально.

Колесо меняет масштаб, фон перетаскивается мышью; персонажей можно передвигать отдельно. «Показать всё» вписывает весь граф. На больших графах приблизьте нужную область или выберите действие/участника. Поиск по названию или алиасу открывает нужную сущность и включает её слой. `/` переводит фокус в поиск; Tab выбирает элементы, стрелки переключают узлы, Enter/Space закрепляют, Escape закрывает читалку или освобождает карточку.

Правую панель можно растянуть за разделитель или изменить стрелками при фокусе на нём. На узком экране касание узла открывает выдвижную карточку. Полная wiki и текст пьесы открываются внутри приложения. В читалке доступны оглавление, подсветка точного блока и возврат к карте/предыдущей странице.

По умолчанию включено основное действие. Упомянутые лица и предыстория, литературные отсылки и редакционный аппарат включаются отдельно. Актёры и роли не отождествляются. Аналитические выводы отмечены знаком ∴; их можно отключить. Пунктир обозначает свидетельство или спор, источник и статус каждого основания сохраняются.

## Обновление данных

Из корня vault выполните:

```powershell
python viewer/export.py --root D:\GIT\bookgraph
```

Команда использует установленный скилл wikibook, выполняет validate → build → validate, проверяет сохранность ручного текста при сборке, метаданные viewer, источники и разрешимость wiki-ссылок, затем записывает `viewer/data.js`. При иной установке скилла добавьте `--skill C:\path\to\wikibook`. Требуются Python 3.10+ и PyYAML из зависимостей скилла. Движок в проект не копируется.

`data.js` — производный пакет, редактировать его вручную не нужно. Изменения карточек до следующего экспорта не видны в браузере. Дата экспорта показана внизу панели фильтров. Внешние URL могут открываться по явной ссылке; приложение не выполняет фоновых сетевых запросов.

## Контракт данных

- `viewer` в YAML frontmatter: `layer` (`story`, `mentioned`, `literary`, `editorial`); для персонажа — `gender`, `gender_sources`, `gender_method`, `importance`, `importance_method`; для события — `act`, `time_group`, `time_rank`, `time_label`, `time_sources`. `time_rank` сохраняет относительный ориентир для других представлений; хронология viewer следует первому появлению в тексте.
- У `related_to` используются дополнительные `relation_type` и `label`; существующие scope/evidence_type/truth_status/sources и ID не меняют смысла. `valid_until` и `at_event` связывают меняющееся отношение с событием.
- Пакет `schema_version: 1` содержит узлы, факты по ID, производные отношения/зависимости, Markdown-страницы, адреса блоков, единицы текста, примечания, дату и хеш входных Markdown.
- Совпадающие отношения одного типа и подписи объединяются, сохраняя все fact_id и индивидуальные статусы. Спорные и опровергнутые утверждения остаются отдельными. Обратные связи вычисляются; `requires` при отображении направлено от условия к событию.

Библиотеки находятся в `vendor`: D3 7.9.0, Marked 15.0.12, DOMPurify 3.3.0. JavaScript загружается обычными локальными script-тегами без ES-модулей и fetch. Markdown проходит очистку DOMPurify. Новые изображения не генерировались.

## Проверка

```powershell
node --check viewer/app.js
node --check viewer/core.js
node viewer/tests.cjs
python scripts/check_vault.py --rebuild-check --write-report
```

13 проверок проекций охватывают направление любви и родства, объединение свидетельств, разворот requires, независимость фильтров анализа/порядка, комбинированные фильтры событий, одно событие на узел, ссылки на повторные появления, отдельный редакционный граф, изолированные события и обход цепочек. Движок wikibook дополнительно проверяет источники и циклы.

Смысловое покрытие и оставшиеся вопросы описаны в `wiki/viewer-audit.bespridannica.md` и `source/bespridannica/viewer-progress.json`. Структурные проверки и смысловой аудит оценивают разные стороны качества; число карточек не доказывает абсолютную полноту.


Сценарии реального браузера сохранены в `checks/`. Для повторения через Playwright CLI (это требуется только для разработки):

```powershell
npx --yes --package @playwright/cli playwright-cli -s=bookgraph open file:///D:/GIT/bookgraph/viewer/index.html --config=viewer/checks/playwright.config.json
npx --yes --package @playwright/cli playwright-cli -s=bookgraph network-state-set offline
npx --yes --package @playwright/cli playwright-cli -s=bookgraph run-code --filename=viewer/checks/browser-cards.js
npx --yes --package @playwright/cli playwright-cli -s=bookgraph run-code --filename=viewer/checks/browser-graphs.js
npx --yes --package @playwright/cli playwright-cli -s=bookgraph run-code --filename=viewer/checks/browser-offline.js
```

Настройка в `checks/playwright.config.json` разрешает Playwright навигацию по `file://`; самому приложению она не нужна. Снимки сохраняются в `output/playwright/` (исключено из Git). Проверены размеры 1520×1020 и 390×844. Машинная сводка — `verification.json`.

Фактически выполнено: 13 проверок проекций и 38 браузерных проверок через `file://` с отключённой сетью; HTTP-ресурсов и ошибок страницы в заключительном сценарии нет. Полная проверка vault: 8132 ссылки, 0 ошибок, 0 предупреждений; две сборки побайтово одинаковы и сохраняют ручной текст. На больших графах выбранный узел/цепочка приближается для чтения; «Показать всё» возвращает обзор.
