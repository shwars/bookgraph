# Генерация изображений в Yandex AI Studio

Установи зависимости в используемое окружение Python 3.11 или новее командой
`python -m pip install -r <путь-скилла>/scripts/requirements.txt`. Запускай
`python <путь-скилла>/scripts/imagen_yart.py` из каталога проекта. В примерах
`<путь-скилла>` обозначает абсолютный путь к этому скиллу. Если в пути есть
пробелы, заключи путь к скрипту в кавычки.

Скрипт загружает `folder_id` и `api_key` напрямую из настроенного HTTPS-файла
`imagen.env` при каждом запуске `generate` и передаёт ключ только клиенту
Yandex AI Studio. Выполняется один запрос генерации. Не загружай файл с ключом
отдельно для просмотра и не включай его содержимое в промпты или логи.

## Обычные изображения

Передай изображаемый сюжет, композицию и стиль через `--prompt` или укажи
UTF-8 файл через `--prompt-file`. Используй `--size 1024x1024` (по умолчанию),
`1024x1536` для вертикали или `1536x1024` для горизонтали. Выходной формат
определяется расширением `.png`, `.jpg` или `.jpeg`. `--size` задаёт
ориентацию и формат кадра для API. Фактическое разрешение выбирает модель.

```text
python <путь-скилла>/scripts/imagen_yart.py generate --prompt "Акварельная набережная ранним утром, пустая площадка на переднем плане" --size 1536x1024 --output quay.png
```

## Персонажи, реквизит и другие прозрачные изображения

Добавь `--transparent` и укажи выходной PNG. Скрипт попросит Alice AI ART
нарисовать объект на ровном зелёном хромакее, сохранит исходник рядом как
`<имя>.source.png` и локально создаст RGBA PNG. Для зелёных деталей предмета
или костюма используй `--key-color magenta`. Подбирай ключевой цвет, которого
нет в объекте. Скрипт сохраняет размеры холста и просветы между частями
объекта. У модели лимит 500 символов на весь промпт, включая автоматически
добавленное описание фона.

```text
python <путь-скилла>/scripts/imagen_yart.py generate --prompt "Один медный фонарь с зелёным стеклом, вид спереди, гуашь" --transparent --key-color magenta --output lantern.png
python <путь-скилла>/scripts/imagen_yart.py generate --prompt "Ростовая акварельная кукла, женщина 40 лет, тёмно-синее платье, короткие каштановые волосы, вид спереди, кисти и обувь целиком" --size 1024x1536 --transparent --output figure.png
python <путь-скилла>/scripts/imagen_yart.py generate --prompt "Акварельный портрет по плечи, женщина 40 лет, короткие каштановые волосы, тёмно-синее платье, лёгкая улыбка, голова целиком" --transparent --output portrait.png
python <путь-скилла>/scripts/imagen_yart.py cutout --input lantern.source.png --key-color magenta --output lantern-cutout.png
```

`cutout` работает без сети. Для него нужен исходник с однотонным зелёным или
пурпурным фоном. После вырезания осмотри силуэт на светлой и тёмной подложках.
Проверь целостность фигуры, детали одежды, волосы, просветы и ореолы. Если
генератор нарисовал неоднородную подложку или тень, уточни промпт и используй
новый выходной путь. Существующие файлы сохраняются.

Для серии поз составь короткий текстовый профиль с чертами лица, возрастом,
причёской, пропорциями и костюмом. Если есть референс, сначала осмотри его и
опиши эти признаки. Повторяй профиль в промптах, меняя позу или выражение.
Сравни варианты рядом, поскольку отдельные генерации могут менять внешность.
Character sheet можно сгенерировать обычной командой `generate`.

Alice AI ART 3.0 работает с текстовым вводом. Прозрачность создаётся локально
после генерации. См. [каталог моделей](https://aistudio.yandex.ru/ru/docs/ai-studio/concepts/generation/models),
[генерацию](https://aistudio.yandex.ru/ru/docs/ai-studio/api/Images/createImage),
[редактирование](https://aistudio.yandex.ru/ru/docs/ai-studio/api/Images/createImageEdit)
и [вариации](https://aistudio.yandex.ru/ru/docs/ai-studio/api/Images/createImageVariation).
