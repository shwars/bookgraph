description: "Создание иллюстраций к основным персонажам и местам"
---

Твоя задача - создать иллюстрации персонажей книги, которые потом можно будет использовать для создания кукольных спектаклей на основе содержимого книги. Иллюстрации персонажей должны быть на прозрачном фоне, чтобы их было легко накладывать на фон. Кроме Character Sheet. Учитывай пожелания пользователя, указанные в промпте при вызове скилла. Если стиль иллюстраций из промпта непонятен - уточни.

Для каждого персонажа из protagonists из книги у которых есть реплики в книге, создай character sheet с основными позами и выражениями лица, а также прозрачные ростовые фигурки персонажа в разных настроениях и крупные выражения лица. Файлы создавай внутри wiki\protagoninsts\images, для персонажа "персонаж.книга.md" назови файлы "персонаж.книга.charsheet.png", "персонаж.книга.front_<настроение>.png" и "персонаж.книга.face_<настроение>.png", где настроение - это neutral / happy / sad / surprised / angry / disgusted.

Для каждого места в wiki\places, создай иллюстрации этого места в формате 16:9. Для места "место.книга.md" создай "место.книга.day.png" и "место.книга.evening.png", они должны быть почти одинаковыми, но могут отличаться источниками света и освещением.
